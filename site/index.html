Find out which jobs your resume already fits.

Upload your resume as a text file. ResumeMatch picks out your skills, scores each section out of 100, and ranks internships by how many of their required skills you already have.

Run it yourself Read the guide

Rule-based analysis: skills are found by matching your resume text against a fixed skill dictionary. No AI or machine learning is involved.

How the analysis works

Every step is plain, explainable logic, built with Java file handling, collections and JDBC.

Upload

Your .txt resume is saved to a resume folder and its path is recorded in the database.

Extract skills

The text is scanned for 18 known skills, such as Java, SQL, JDBC and Git, grouped by category.

Score

Skills, projects, education, certifications and experience earn points toward a score out of 100.

Match and rank

Each job is compared with your skill set, then sorted from best to weakest match.

Match score matched required skills ÷ total required skills × 100 4 of 5 required skills = 80% match

Run it yourself

ResumeMatch is a Java servlet application backed by MySQL, so it runs on your own computer or server rather than on this page. You need JDK 17, MySQL 8 and Apache Tomcat 9.

git clone https://github.com/Barathkumar-17/ResumeMatch.git
cd ResumeMatch
mysql -u root -p < database/01_schema.sql
mysql -u root -p < database/02_seed_data.sql
./build.sh deploy        # or build.bat deploy on Windows

Then open http://localhost:8080/ResumeMatch/ and sign in with demo@resumematch.in / demo1234. The README covers the jars, database settings and troubleshooting.
